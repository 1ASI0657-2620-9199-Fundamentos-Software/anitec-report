# 5.3. Microservices Implementation

En esta sección se explica y evidencia el proceso de implementación, pruebas, documentación y despliegue de los Web Services de AniTec, organizado por Sprints. Cada Sprint registra su Sprint Backlog, la evidencia de desarrollo, de pruebas y de ejecución, la documentación de los endpoints, la evidencia de despliegue y los análisis de colaboración del equipo.
